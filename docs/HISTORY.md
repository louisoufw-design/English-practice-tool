# 開發紀錄與設計決策

這份記錄這個網站「做了什麼、為什麼這樣做」，方便之後接手或回顧。技術細節請看根目錄的 `AGENTS.md`。

## 目標
- 為台灣的英文學習者做一個「看《Modern Family》學美式口語」的網站。
- 選這部劇是因為對白很接近美國人的日常口語。
- 照集數整理常用片語，搭配間隔複習、造句、情境挑戰，讓學到的說法真的講得出來。
- 設計前提：手機為主、用零碎時間練習。

## 時間線
1. **第一版**：S01E01、S01E02，一集一頁，選季／選集頁。
2. **記憶系統**：
   - 遺忘曲線複習（每天上限 10 個）、休假模式（暫停並順延排程）、每週可漏一天不斷連續天數。
   - 回想卡片（看中文 → 講英文 → 翻面 → 忘了／模糊／想起來了）。
   - 每日 3 題情境挑戰。
   - 造句本 + Claude 審核（很自然／小修正／片語用法有問題，可採用修正版）。
   - 進度頁（月曆、熟練度）。
   - claude.ai Artifact 內建資料庫：每位使用者各自的雲端進度。
3. **介面調整**：
   - 「搞定」按鈕（按了顯示「記憶中 · 日期」，再點可取消）。
   - 首頁迷你月曆、片語盲盒、今日學習（睡前全部播放）、今日一句。
   - 片語改用底線標示、固定導覽列。
   - 修正雲端快照造成的畫面閃爍。
4. **完成 11 季 250 集**：
   - 每集 10 個片語，全站不重複，共 2,510 個。
   - 劇情參考英文維基百科各季頁面；例句為原創生活句，不是劇本原文。
5. **看劇學英文強化**：
   - 防劇透（未標記看完的集數劇情模糊）。
   - 追劇進度（我看完這集了、首頁追劇卡、選集 ✓／下一集）。
   - 找片語（搜尋 + 10 類主題 + 基礎／進階 + 只看沒學過的；主題分類由 AI 批次標註）。
6. **版面精簡**：
   - 篩選收合、搜尋一次 15 筆。
   - 我的金句移到首頁、今日例句移到造句本。
   - 各季進度改成圓環格子，集數寫成「S01 E01」。
7. **語塊（word chunks）**：
   - 造句審核加入語塊／搭配詞檢查，並推薦「多學一個搭配」，可一鍵收藏。
8. **收藏字詞（類似 Toko）**：
   - 例句裡點字就能收藏，Claude 補上中文、用法和例句。
   - 也能手動輸入看劇聽到的字。
   - 複習時改成「用它造一句 → Claude 檢查 → 自評」。
9. **挑戰題多元化**：
   - 原本約 4 成跟當兵有關，改成工作、學校、朋友、家人、旅行、運動等各種主題。
   - 軍旅題目約只保留 1/10。

## 設計偏好
- 介面要「輕」：避免一長串文字、要滑很久的頁面；偏好一眼看懂的視覺化摘要。
- 用字用台灣習慣，自然但不要太白話；按鈕用語要精準。
- 大改版時提供幾種不同風格讓站長選，避免每次設計都長得差不多。
- 手機優先。

## 部署現況
- 線上版：claude.ai Artifact（`YOUR_ARTIFACT_URL`）。在 claude.ai 登入時才有雲端同步與 Claude 審核／查字。
- 本機或一般網站：自動進入「本機模式」，進度存在瀏覽器 localStorage，沒有 AI 功能，其他功能完整。
- 自架方案（尚未實作）：
  - GitHub Pages：放網站。
  - Firebase：登入與進度同步。
  - 伺服器端中繼：Cloudflare Worker／Firebase Function 呼叫 Anthropic API。
  - 金鑰只能放在伺服器端環境變數（見 `.env.example`）。
